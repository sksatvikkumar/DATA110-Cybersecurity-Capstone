# DATA110-Cybersecurity-Capstone
Cybersecurity Capstone Project for DATA 110 – Introduction to Python and Machine Learning
Problem Statement
The goal is to predict the type of cyber attack associated with a security incident.
Dataset
100,000 records
15 attributes
8 attack types
No missing values
Machine Learning Models
Logistic Regression
Decision Tree
Random Forest
Artificial Neural Network (ANN)
Methodology
Data Cleaning → EDA → Feature Engineering → Train/Test Split → Model Training → Hyperparameter Tuning → Evaluation
Evaluation Metrics
Accuracy
Precision
Recall
F1 Score
ROC-AUC
Results
Random Forest achieved the highest accuracy among the four tested models.
